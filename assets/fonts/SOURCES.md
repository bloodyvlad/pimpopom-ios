# Font sources

No font has been accepted into PimPoPom yet.

Before migrating or adding a font, record its exact family/version, upstream URL, licence and retained licence file, unmodified versus subset/converted state, glyph/language coverage, file hashes, Dynamic Type/accessibility role, and first shipped build. Verify that App Store redistribution and any branding use are permitted.

The migration baseline used Pixelify Sans for one theme under the SIL Open Font License. If selected for PimPoPom, copy the exact reviewed font and licence together and revalidate hashes rather than relying on this note.
